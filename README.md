# NOX Portfolio

The complete NOX portfolio site in desktop and dedicated mobile versions. It uses plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Open the site

- Open this folder in Visual Studio Code.
- Open `index.html` for the main desktop/responsive site.
- Open `mobile.html` for the dedicated mobile layout with swipeable team, work, and app-filter strips.
- For the best preview in VS Code, use the Live Server extension and open either HTML file.

## Project files

- `style.css`, `script.js`, and `images/`, `videos/`, `pdfs/` are shared by both versions.
- `mobile.css` contains the mobile-only layout rules.
- PDFs and videos open from the work cards; keep the asset folders beside the HTML files.

The Sabrina Carpenter cover photo on the Spotify Edit card loads from Wikimedia Commons and needs an internet connection. Its photographer and license links are shown in the video dialog.
